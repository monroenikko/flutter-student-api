# Implementation Plan Archiving Rule

- Whenever creating or completing an implementation plan for a new feature, API, or module:
  - Save a copy of the plan as `<title_of_the_implementation>.md` (e.g. `student_class_schedule_api.md`) in the `implemented-plans/` folder in the project root.
  - Keep all implementation plans structured with requirements, affected files, API schema, database safety constraints, and testing steps.
